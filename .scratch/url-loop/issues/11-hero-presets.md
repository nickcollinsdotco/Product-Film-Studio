# 11: Presets that show only their three hero controls

**Type:** task
**Status:** done (tested locally, UI screenshots inspected 2026-10-18)
**Blocked by:** —

**Source:** React Bits Center Stage's preset gallery (idea only).

Quick Loop opens on a **Preset** grid: Glide, Glide and return, Zoom to detail, Open on detail, Flat, Phone and Agent build. Agent build needs a captured URL. Each tile plays its preset on the current image (a 480 px copy) when hovered, and rests on a poster frame otherwise. Choosing a preset sets the look and motion; the image, focus area, colour and output stay. Its 3 hero controls move up under the grid, and everything else sits under **All settings**.

The preset list and each preset's hero controls are my choices (reversible); change them in `PRESETS` in `tools/quick-loop/app.html`.
