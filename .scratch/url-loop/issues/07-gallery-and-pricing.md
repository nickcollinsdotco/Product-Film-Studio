# 07: Public gallery and pricing pattern (only if B goes public)

**Type:** research
**Status:** open
**Blocked by:** 01

Patterns from snapcn's site worth copying if B goes public:

- A gallery where each item has its own page with a live autoplaying preview, used as both docs and marketing.
- An `llms.txt` and an agent skill so coding agents can use the tool.
- Free output with a small mark; pay to remove it and get the higher resolution. Their prices: Pro about €115/yr, Lifetime about €222, Commercial about €446 (see `../map.md`).

Don't build any of this before 01 shows pull, and don't add a paid tier before someone asks to pay.
