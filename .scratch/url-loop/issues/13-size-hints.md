# 13: Size hints and a sharpness warning

**Type:** task
**Status:** done (tested 2026-10-18)
**Blocked by:** —

**Source:** React Bits Center Stage's "an iPhone 16 Pro screenshot fits exactly" guide (idea only).

Under the Screen image, a hint per viewport says which screenshot fits exactly. When the image is narrower than 90% of the widest the Loop shows it (the card at full zoom, from the composition's `quick.need`), an amber warning says so. For example: "Soft at its largest: the Loop shows this image up to 3,078 px wide and it is 1,600 px."
